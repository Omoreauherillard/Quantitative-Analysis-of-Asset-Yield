The goal of this project is to analyse whenever the price of an asset (here S&P 500 and NASDAQ 100) is overvalued or undervalued, in order to optimize a regular long term investment strategy, which consist in buying periodically an asset whitout never selling it.

To do it, i chose to compare the current return of the previous year (only the price return, not taking in account the dividends), with the annualized return (CAGR).
When the current return will be over the CAGR, i will consider to have the opportunity to buy more than usually, and vice-versa when the current return is under the CAGR.



Idea : use a genetic alogrithm to determine the best function (gap -> invest of the month) for investing
